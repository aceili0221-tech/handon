# 🏢 企業內部出勤與工時打卡系統 (本地執行版)

本系統為專為企業內部設計之現代化出勤與工時管理系統，支援**辦公室內勤打卡**、**外勤 GPS 案場雷達簽到**、**請假加班審核**、**在職員工狀況編輯與組織管理**、**即時管理儀表板**、**無亂碼 UTF-8 BOM CSV 匯出**以及**離線打卡快取同步**。

---

## ⚡ 本地電腦執行方式

### 方式 A：🍏 macOS 一鍵雙擊（桌面瀏覽器版本）
1. 在 Finder 中找到專案資料夾內的 **`start-mac.command`**。
2. **連點兩下（雙擊）`start-mac.command`**。
3. 系統將自動檢查環境、安裝依賴，並**自動喚起您的預設桌面瀏覽器開啟 `http://localhost:3000`**。

> 💡 **首次執行提示**：若 macOS 跳出安全性提示，只需右鍵點擊 `start-mac.command` 選擇「開啟」即可。

---

### 方式 B：🪟 Windows 一鍵雙擊
1. 在檔案總管中找到專案資料夾內的 **`start-windows.bat`**。
2. **連點兩下（雙擊）`start-windows.bat`**。
3. 系統將自動啟動並在瀏覽器中開啟 `http://localhost:3000`。

---

### 方式 C：🖥️ 獨立桌面視窗應用程式 (Electron 原生視窗)
若您想要像 Slack、LINE、VS Code 一樣以獨立軟體視窗運行（免開瀏覽器標籤頁）：
```bash
npm run app
```
系統會直接開啟原生桌面視窗，關閉視窗時自動結束背景服務。

---

### 方式 D：💻 終端機常用指令

| 目的 | 指令 | 說明 |
| :--- | :--- | :--- |
| **一鍵啟動並開啟瀏覽器** | `npm run start:browser` | 啟動伺服器並自動開啟預設桌面瀏覽器 |
| **開啟 Electron 桌面視窗** | `npm run app` | 以獨立桌面原生視窗模式執行 |

| **生產模式啟動** | `npm start` | 運行打包後的正式版伺服器 |

## 👥 在職員工狀況編輯與組織管理（管理員專區）

在系統頂部導航欄點選 **「人員組織管理」** 頁籤，即可進入完整的在職員工名冊與狀況管理後台：

1. **即時編輯在職狀況 (Employment Status)**：
   - 可隨時將同仁切換為：
     - 🟢 **在職出勤 (Active)**：正常出勤排班
     - 🔴 **休假請假 (Leave)**：特休、事假、病假等休假狀態
     - 🔵 **居家遠端 (WFH)**：在家工作或異地辦公
     - 🟣 **公差出差 (Business Trip)**：前往外縣市或客戶端出差
     - ⚪ **已離職/除名 (Resigned)**：除名保留紀錄
   - 支援在卡片或表格上一鍵下拉切換，亦可在「編輯彈窗」中詳細修改。
2. **編輯員工基本資料**：
   - 隨時修改員工姓名、所屬部門（支援預設或自訂部門）、職稱、排班班表（標準班、彈性班、責任制、巡檢班）、聯絡電話、Email、到職日期與工作備註。
3. **新增在職員工入職**：
   - 點擊右上角「新增人員入職」，輸入資料後自動分配工號（如 `EMP-007`），各打卡選單立即同步更新。
4. **人員除名與刪減**：
   - 具備防呆確認視窗，除名後自簽到選單中移除，但**歷史打卡與假單紀錄依然完整保留**於資料庫中。
5. **部門與狀況快速篩選**：
   - 支援依在職狀況（在職/休假/WFH/出差）與部門標籤即時過濾，並支援關鍵字搜尋。
   - 提供「卡片視圖」與「清單表格」兩種模式。
6. **匯出在職員工名冊**：
   - 一鍵匯出包含 UTF-8 BOM 的 Excel 相容 CSV 員工名冊。

## 📱 手機 / 平板同區網打卡（行動外勤支援）

當伺服器在您的電腦上啟動時，終端機會顯示您的區域網路 IP，例如：
```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   🏢 企業內部出勤與工時打卡系統 (本地伺服器已正常啟動)        │
│                                                              │
│   💻 本機電腦瀏覽器請點開：  http://localhost:3000               │
│   📱 同 WiFi 手機/平板打卡： http://192.168.1.114:3000           │
│   📁 本地打卡資料檔案：      ./attendance_logs.json          │
│   👥 本地員工名冊檔案：      ./employees.json                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
只要您的手機或平板連線至**同一個辦公室 Wi-Fi**，在手機瀏覽器中輸入該區網網址（例如 `http://192.168.1.114:3000`），即可直接用手機進行 GPS 定位打卡或請假登記！

## 💾 資料儲存與備份說明

1. **本地 JSON 資料庫**：
   - 出勤紀錄：儲存在根目錄的 `attendance_logs.json`。
   - 員工名冊：儲存在根目錄的 `employees.json`。
   - 伺服器端資料自動永久保存在這兩個檔案中，您可以直接備份或複製。
2. **瀏覽器雙重備份 (LocalStorage)**：
   - 即使電腦伺服器短暫中斷，前端打卡動作會自動寫入瀏覽器離線隊列，待伺服器恢復連線後自動重試同步。
3. **報表與名冊匯出**：
   - 管理員可在「管理看板」點擊「匯出出勤報表 (CSV)」以及在「人員組織管理」點擊「匯出名冊 (CSV)」，系統自動注入 UTF-8 BOM，保證以 Microsoft Excel 開啟時繁體中文絕無亂碼。
